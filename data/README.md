# RADIANT data directory

- `synthetic/` — RADIANT-authored synthetic reports (clearly labeled).
- `sample_xrays/` — synthetic placeholder images for UI/wiring tests only.
- `knowledge_base/` — RAG development fixtures and, later, licensed sources.
- `nih/` — NIH ChestX-ray14 subset (git-ignored; not committed).
- `radsprl/` — Rad-SpRL files (git-ignored; not committed).

Nothing in this folder is a clinical source. See `docs/datasets.md`
(added in Stage 3) for licenses and provenance.
